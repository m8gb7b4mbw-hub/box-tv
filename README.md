# Box TV

Écran d'accueil pour box Android TV, servi par mon NAS Ugreen.

- `app/` : la petite appli Android (affiche la page du NAS en plein écran et lance les applis de la box).
- `nas/home.html` : la page d'accueil, à copier dans le dossier `IPTV/public` du NAS.
- `nas/index.html` : l'appli IPTV pilotable à la télécommande, à copier aussi dans `IPTV/public`.

## Installer l'appli sur la box
Downloader → `https://github.com/m8gb7b4mbw-hub/box-tv/releases/latest/download/box-tv.apk`

## Réglages de l'appli
- Adresse par défaut : `http://100.99.4.38:8080/home.html`
- Appui long sur **Retour** (ou touche Menu) : changer l'adresse / ouvrir les réglages Android.
